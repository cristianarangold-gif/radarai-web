# Tuits del día

Un archivo por día (`AAAA-MM-DD.md`) con el tuit que propone la rutina diaria. Cristian lo publica en X con el enlace de «publicar con un toque» y luego fusiona la PR, que queda como registro para no repetir tema.

Formato, normas y pasos: `docs/rutina-tuits.md`. Comprobación: `python scripts/tweet.py social/x/AAAA-MM-DD.md`.

Cómo verificar una respuesta de IA

Una respuesta clara y segura puede contener errores. La verificación debe adaptarse a la importancia de la información.

Primero identifica qué puede fallar

  • Fechas y cifras.
  • Nombres y citas.
  • Datos técnicos.
  • Interpretaciones y conclusiones.
  • Información que haya cambiado recientemente.

Busca la fuente adecuada

Para información oficial, prioriza la fuente primaria correspondiente. Para temas académicos, utiliza fuentes académicas o institucionales. Para decisiones importantes, contrasta más de una fuente fiable.

Comprueba el contexto

No basta con confirmar una frase aislada. Comprueba si la fuente dice realmente lo mismo y si la fecha o las condiciones coinciden.

Regla práctica: cuanto mayor sea el impacto de un error, mayor debe ser el nivel de verificación.

Qué no hacer

No consideres una respuesta correcta simplemente porque incluye enlaces, cifras o un tono convincente. La apariencia no sustituye a la comprobación.
